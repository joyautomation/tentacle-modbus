# tentacle-modbus

Modbus TCP scanner for the [Tentacle IIoT Platform](https://github.com/joyautomation/tentacle-docs). Supports all four register spaces (coils, discrete inputs, holding registers, input registers), block reads, and multi-word datatypes (float32, int32, etc.).
